# Секреты Тёмнолесья — SQL-анализ игровых покупок

Исследование покупательской активности игроков в фэнтезийной игре: доля платящих игроков, статистика внутриигровых покупок, популярность эпических предметов и зависимость активности от расы персонажа.

**Стек:** PostgreSQL · SQL (CTE, оконные функции, агрегаты)

---

##  Цель проекта

Изучить, как характеристики игроков и их персонажей влияют на покупку внутриигровой валюты «райские лепестки», и оценить активность игроков при совершении внутриигровых покупок.

## 🧬 Схема данных

Все данные лежат в схеме `fantasy` и состоят из 7 таблиц:

| Таблица   | Ключевые поля                                              | Описание                          |
|-----------|--------------------------------------------------------------|------------------------------------|
| `users`   | `id`, `payer`, `race_id`, `class_id`, `ch_id`                | игроки                             |
| `race`    | `race_id`, `race`                                             | справочник рас персонажей          |
| `classes` | `class_id`, `class`                                           | справочник классов персонажей      |
| `events`  | `transaction_id`, `id`, `item_code`, `amount`, `date`         | покупки предметов                  |
| `items`   | `item_code`, `game_items`                                     | каталог эпических предметов        |
| `skills`  | `ch_id`, `legendary_skill`                                    | легендарные навыки персонажей      |
| `country` | `loc_id`, `location`                                          | страна/регион игрока               |

##  Что сделано

**Часть 1. Исследовательский анализ данных**
- Доля платящих игроков по всей игре и в разрезе рас
- Статистика по стоимости покупок (мин/макс/среднее/медиана/стандартное отклонение)
- Поиск и оценка доли аномальных (нулевых) покупок
- Рейтинг популярности эпических предметов

**Часть 2. Ad hoc-задача**
- Зависимость активности игроков по покупке эпических предметов от расы персонажа

Все запросы — в [`darkwood_secrets.sql`](darkwood_secrets.sql).

##  Как запустить

1. Подключитесь к базе PostgreSQL со схемой `fantasy`.
2. Выполните запросы из `darkwood_secrets.sql` целиком или по частям (каждый блок снабжён комментарием с номером задачи).
